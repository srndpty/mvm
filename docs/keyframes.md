# モーションキーフレーム

動画・画像・Manim・文字で、位置 X/Y、拡大率 X/Y、回転、クロップ上下左右、不透明度をアニメーションできます。音声では音量を編集できます。

## 操作

1. クリップを選択し、クリップ内のフレームへ再生ヘッドを移動します。
2. エフェクトコントロールの時計ボタンをオンにすると、現在の表示値で最初のキーを作ります。
3. 別のフレームで数値を変更すると、その位置にキーを追加・更新します。プレビュー上の移動・拡縮も同じ編集に反映します。
4. 菱形ボタンで現在位置のキーを追加・削除し、左右のボタンで前後のキーへ移動します。曲線上へ追加したキーは曲線を変えず、そのキーを削除すると前後の区間を元の曲線へ結合し直します。
5. 小タイムラインのキーを横へドラッグして位置を変更します。同じ項目の既存キーと重なる位置は受理しません。
6. キーを右クリックすると、そのキーから次のキーまでの補間を変更できます。現在と同じ補間を選んでも何も変えません（分割・トリムで残した部分曲線を保ちます）。

数値欄はシングルクリックで直接入力できます。Ctrl+←/→ で操作対象の項目の前後キーへ移動します。

小タイムラインの空白をクリックするとシークし、ドラッグするとスクラブします。グラフの空白をドラッグすると矩形内のキーを複数選択できます。Ctrl/Shiftを押しながらの矩形選択は既存の選択へ追加します。Deleteで選択キーをまとめて削除し、Escで選択ドラッグを取り消します。キーをクリックすると青い選択表示になり、Ctrl+クリックで複数選択できます。キーにフォーカスがある状態で Ctrl+C/X/V を使うとコピー・カット・ペーストできます。別項目の項目名または小タイムラインをクリックして貼り付けることで X→Y などの転用もできます。最初のコピー元キーを再生ヘッドへ合わせ、相対間隔を保ちます。貼り付け先の同位置キーは置き換えます。範囲外の値や尺外のキーを含む場合は操作全体を拒否します。

「カーブ」を開くと値のグラフを表示します。キーは時間と値をドラッグで編集できます。選択キーの後続区間に表示される丸いハンドルを上下へドラッグすると三次スプラインへ切り替わります。時間方向の制御位置は区間の1/3と2/3で固定し、値の制御位置は両端値の間に制限します。オーバーシュートと空間軌道の編集は含みません。

補間はリニア、イーズイン、イーズアウト、イーズインアウト、スプラインです。回転は入力した角度を直接補間します。例えば 350 度から 10 度へは減少する方向に動きます。

時計ボタンをオフにすると現在の評価値を固定値へ移し、キーを削除します。最後のキーを削除したときも現在値を固定値として残します。ドラッグは確定時に一回の Undo となり、Esc で取り消せます。確定（保存）に失敗した場合はドラッグ中の表示を破棄し、元の値へ戻します。再生中は編集を無効にします。選択クリップの区間外でも既存キー・曲線を編集できます。区間外でのキー追加・数値入力・貼り付けはクリップ先頭を基準にします。

## 編集と保存

分割・トリムでは境界キーと元の曲線の進捗範囲を保存し、残った区間の動きを保ちます。クリップ移動・リップル・スリップではクリップ内のキー位置を変えません。速度変更では尺に合わせてキー位置を換算します。フレーム保持でもモーションは継続し、保持後のクリップは保持した尺だけ進んだ位置からモーションを再開します（映像だけが止まり、動きはタイムラインの時間で進みます）。

保存形式は schema 15 です。schema 14 以前のファイルは明示的に拒否し、自動変換しません。

プレビューと書き出しは project 層の共通評価器を使用します。書き出しでは評価済みの各フレームの幾何情報を MLT へ渡します。不透明度・音量のフェードとトランジション係数は別に掛けます。既存のディゾルブの素材・全画面・不透明条件は維持します。

モーションブラー、フェード尺のキーフレーム編集は含みません。
