# オーディオミキサー

左パネルの「オーディオミキサー」タブに音声トラックとマスターを表示する。トラックが増えたら横にスクロールできる。

- パンは上下・左右のドラッグで変更する。Ctrlを押すと移動量が通常の1/10になる。ダブルクリックで中央へ戻り、数字のシングルクリックで−100（左）〜100（右）を直接入力できる。中央では左右とも減衰せず、端へ寄せると反対側のチャンネルを減衰する。
- 縦フェーダーは無音〜+15 dB。Ctrlで微調整、ダブルクリックで0 dBへ戻る。下の数字はシングルクリックで編集でき、`-inf` または `-∞` で無音にできる。範囲外や数値以外の入力は確定しない。
- M/SはタイムラインのMute/Soloと同じ状態を使う。
- メーターは通常再生で消費したPCMをトラックごとに合算して測る。黄色線は直近1秒の最大値。0 dBを超えると赤ランプが残り、クリックで解除する。信号が再び超過すれば再点灯する。
- 下部の名前はミキサー専用で、タイムラインのA1、A2などは変わらない。Enterまたはフォーカス移動で確定し、Escで取り消す。音量・パン・名前はプロジェクトに保存し、Undo/Redoの対象になる。ドラッグ途中では履歴を増やさず、離した時に1回として確定する。
- プレビュー右側とミキサーのマスターは同じモニター音量を操作する。マスターの横向きスライダーは縦フェーダーへ置き換えた。トラックの音量・パンは書き出しにも適用する。

操作の検査は `audio_mixer_controls_qml`、PCMと保存の検査は `audio_mixer_pcm_and_project`、製品パネルとWASAPI出力の検査は `audio_mixer_product_ui` に登録している。性能測定ではない。
